# Тестовый режим аналитики

Тестовый режим предназначен только для проверки аналитики портфолио. Он добавляет
к событиям GA4 параметр `debug_mode`, чтобы фильтр `Developer traffic testing`
мог отличить их от обычного трафика.

## Как включить

Откройте любую страницу сайта с параметром `analytics_debug=1`, например:

```text
https://sevakudryavtsev.com/?analytics_debug=1
```

Режим действует только в текущей вкладке и сохраняется при переходах внутри
сайта. Его можно проверить в GA4 DebugView.

## Как выключить

Закройте вкладку или откройте страницу с `analytics_debug=0`:

```text
https://sevakudryavtsev.com/?analytics_debug=0
```

## Настройка GA4

В GA4 создан фильтр `Developer traffic testing` с операцией Exclude и состоянием
Testing. Пока он только помечает отладочные события в измерении `Test data filter
name`; исключение из основных отчётов включать только после проверки в течение
24–36 часов.
